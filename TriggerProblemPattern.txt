PATTERN 1 — FIELD AUTO POPULATION
Problems
1, 2, 9, 12, 22, 25, 61

Trigger Event
before insert / before update

Handler Method
beforeInsert(Map<Id,SObject> newMap)

Data Structures
Map + List

Map Usage
Use `Trigger.newMap` so lookup is easier if related data is needed.

Flow

1 Loop records from map.values()
2 Apply field rule
3 Save values before DML

Example

Trigger

```
trigger LeadTrigger on Lead (before insert){
    LeadHandler.setRating(Trigger.newMap);
}
```

Handler

```
public class LeadHandler{

    public static void setRating(Map<Id,Lead> newMap){

        for(Lead l : newMap.values()){

            if(l.LeadSource == 'Web'){
                l.Rating = 'Cold';
            }else{
                l.Rating = 'Hot';
            }

        }

    }

}
```

# MAP-CENTRIC TRIGGER TEMPLATE (BEST PRACTICE)

```
trigger AccountTrigger on Account(
before insert,
before update,
before delete,
after insert,
after update,
after delete,
after undelete
){

    AccountHandler handler = new AccountHandler();

    if(Trigger.isBefore){

        if(Trigger.isInsert)
            handler.beforeInsert(Trigger.newMap);

        if(Trigger.isUpdate)
            handler.beforeUpdate(Trigger.newMap,Trigger.oldMap);

        if(Trigger.isDelete)
            handler.beforeDelete(Trigger.oldMap);

    }

    if(Trigger.isAfter){

        if(Trigger.isInsert)
            handler.afterInsert(Trigger.newMap);

        if(Trigger.isUpdate)
            handler.afterUpdate(Trigger.newMap,Trigger.oldMap);

        if(Trigger.isDelete)
            handler.afterDelete(Trigger.oldMap);

    }

}
```

# Pattern 1 — Serial Number Generation (Problem 32)

Goal
If 3 products added → serial numbers **1,2,3**
If product deleted → next product should still be **4**

### Logic Flow

1 Collect OpportunityIds
2 Query existing OLI count
3 Generate serial number
4 Update new records

### Handler Example

```apex id="oli_handler_serial"
public static void assignSerialNumbers(
    Map<Id,OpportunityLineItem> newMap
){

    Set<Id> oppIds = new Set<Id>();

    for(OpportunityLineItem oli : newMap.values()){
        oppIds.add(oli.OpportunityId);
    }

    Map<Id,Integer> countMap = new Map<Id,Integer>();

    for(AggregateResult ar :
        [SELECT OpportunityId oppId, COUNT(Id) cnt
         FROM OpportunityLineItem
         WHERE OpportunityId IN :oppIds
         GROUP BY OpportunityId]){

        countMap.put(
            (Id)ar.get('oppId'),
            (Integer)ar.get('cnt')
        );
    }

    List<OpportunityLineItem> updates =
        new List<OpportunityLineItem>();

    for(OpportunityLineItem oli : newMap.values()){

        Integer seq = countMap.get(oli.OpportunityId);

        oli.Serial_No__c = String.valueOf(seq);

        updates.add(oli);
    }

    update updates;
}
```

# Pattern 2 — Update Parent Totals (Problems 77,79)

Example
Update **Total Products / Total Opportunity Amount on Account**

### Flow

1 Collect OpportunityIds
2 Query Opportunity → AccountId
3 Query OLIs
4 Calculate totals
5 Update Account

### Handler Example

```apex id="oli_handler_totals"
public static void updateAccountTotals(
    Map<Id,OpportunityLineItem> newMap
){

    Set<Id> oppIds = new Set<Id>();

    for(OpportunityLineItem oli : newMap.values()){
        oppIds.add(oli.OpportunityId);
    }

    Map<Id,Opportunity> oppMap =
        new Map<Id,Opportunity>(
        [SELECT Id,AccountId
         FROM Opportunity
         WHERE Id IN :oppIds]);

    Set<Id> accIds = new Set<Id>();

    for(Opportunity opp : oppMap.values()){
        accIds.add(opp.AccountId);
    }

    Map<Id,Decimal> totalMap = new Map<Id,Decimal>();

    for(AggregateResult ar :
        [SELECT Opportunity.AccountId accId,
         SUM(TotalPrice) total
         FROM OpportunityLineItem
         WHERE Opportunity.AccountId IN :accIds
         GROUP BY Opportunity.AccountId]){

        totalMap.put(
            (Id)ar.get('accId'),
            (Decimal)ar.get('total')
        );
    }

    List<Account> updates = new List<Account>();

    for(Id accId : totalMap.keySet()){

        updates.add(new Account(
            Id = accId,
            Total_Opportunity_Amount__c = totalMap.get(accId)
        ));

    }

    update updates;
}
```

# Pattern 3 — Product Inventory Deduction (Problem 57)

Goal
Reduce **Available Quantity** in Product2 when product sold.

### Flow

1 Collect ProductIds
2 Query Product2 records
3 Deduct quantity
4 Update products

### Handler Example

```apex id="oli_handler_inventory"
public static void updateInventory(
    Map<Id,OpportunityLineItem> newMap
){

    Set<Id> productIds = new Set<Id>();

    for(OpportunityLineItem oli : newMap.values()){
        productIds.add(oli.PricebookEntry.Product2Id);
    }

    Map<Id,Product2> productMap =
        new Map<Id,Product2>(
        [SELECT Id,Available_Quantity__c
         FROM Product2
         WHERE Id IN :productIds]);

    List<Product2> updates = new List<Product2>();

    for(OpportunityLineItem oli : newMap.values()){

        Product2 prod =
            productMap.get(oli.PricebookEntry.Product2Id);

        prod.Available_Quantity__c -= oli.Quantity;

        updates.add(prod);
    }

    update updates;
}
```
