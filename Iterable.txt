“Iterator works using a cursor (index) that moves step-by-step using hasNext() and next(), ensuring safe and controlled traversal without modifying the collection.”
What is an Iterator in Salesforce Apex?

An Iterator allows you to:

Traverse elements in a collection
Access elements one by one
Prevent modification of the collection while iterating
🔹 Why use Iterator instead of a for loop?

Using an iterator gives you:

✅ Read-only access (prevents accidental modification)
✅ Safer iteration (avoids runtime errors)
✅ Better control over traversal



NOTE-->ConcurrentModificationException
ex-->
Iterator<Integer> itr = nums.iterator();
while (itr.hasNext()) {
    Integer n = itr.next();
    
    nums.add(5); // ❌ same error
}


public class SimpleIteratorDemo {

    public static void run() {
        
        // 🔹 Step 1: Create list
        List<String> names = new List<String>{'A', 'B', 'C'};
        
        // 🔹 Step 2: Get iterator
        Iterator<String> itr = names.iterator();
        
        // 🔹 Step 3: Loop using iterator
        while (itr.hasNext()) {
            
            // hasNext() → check next element hai ya nahi
            
            String value = itr.next();
            // next() → next value deta hai
            
            System.debug('Value: ' + value);
        }
    }
}

# 🔷 🟢 PART 1: Normal Code (Iterator + Iterable)

## ✅ Single Flow Example

```apex id="normal01"
public class DemoIterable implements Iterable<Integer> {

    // Iterable ka kaam → iterator dena
    public Iterator<Integer> iterator() {
        return new DemoIterator();
    }
}

// Iterator class
public class DemoIterator implements Iterator<Integer> {

    Integer num = 1;

    public Boolean hasNext() {
        return num <= 5;
    }

    public Integer next() {
        return num++;
    }
}
```

## 🔹 Use it

```apex id="normal02"
DemoIterable obj = new DemoIterable();

for (Integer i : obj) {
    System.debug(i);
}
```

# 🔷 🟡 PART 2: SAME CONCEPT IN BATCH

Ab wahi cheez Batch me use karte hain 👇

---

## ✅ Batch Class

```apex id="batch11"
global class DemoBatch implements Database.Batchable<Integer> {

    // 🔹 start method
    global Iterable<Integer> start(Database.BatchableContext bc) {
        
        // yaha hum Iterable return kar rahe hain
        return new DemoIterable();
    }

    // 🔹 execute
    global void execute(Database.BatchableContext bc, List<Integer> scope) {
        
        for (Integer i : scope) {
            System.debug('Processing: ' + i);
        }
    }

    // 🔹 finish
    global void finish(Database.BatchableContext bc) {
        System.debug('Done');
    }
}
```

---

## 🔹 Run Batch

```apex id="batch12"
Database.executeBatch(new DemoBatch(), 2);
```

---

# 🔷 🔥 HOW INTERFACE WORKS IN BATCH (CORE CONCEPT)

## 🔍 Step-by-Step Flow

```text id="flow03"
1. Batch start() called

2. start() returns → DemoIterable

3. Salesforce internally:
   calls iterator()

4. Iterator se data milta hai:
   1,2,3,4,5

5. Batch divide karta hai:
   [1,2], [3,4], [5]

6. execute() multiple times run hota hai

7. finish() end me call hota hai
```

# 🔷 🧠 SIMPLE CONNECTION (MOST IMPORTANT 🔥)

| Concept  | Role                                |
| -------- | ----------------------------------- |
| Iterable | Data provide karta hai              |
| Iterator | Data ko ek-ek karke deta hai        |
| Batch    | Data ko chunks me process karta hai |
