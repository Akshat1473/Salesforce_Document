 🔥 LWC COMPLETE BEGINNER SHEET (WITH PROPERTIES)

## 🔷 1. TEMPLATE & DIRECTIVES

| Tag                      | Important Properties          | HTML Example                                                                                    | JS                              | Hinglish Use                   |
| ------------------------ | ----------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------ |
| `<template>`             | root                          | `html<br><template><h1>Hello</h1></template>`                                                   | ❌                               | Har component ka base hota hai |
| `<template lwc:if>`      | `lwc:if={condition}`          | `html<br><template lwc:if={show}><p>Visible</p></template>`                                     | `js<br>show=true;`              | Condition true ho tab show     |
| `<template lwc:elseif>`  | `lwc:elseif={cond}`           | `html<br><template lwc:elseif={alt}></template>`                                                | `js<br>alt=false;`              | Multiple conditions            |
| `<template lwc:else>`    | no property                   | `html<br><template lwc:else>Else</template>`                                                    | ❌                               | Default fallback               |
| `<template for:each>`    | `for:each`, `for:item`, `key` | `html<br><template for:each={list} for:item="item"><p key={item.id}>{item.name}</p></template>` | `js<br>list=[{id:1,name:'A'}];` | Loop chalana                   |
| `<template iterator:it>` | `iterator:name`               | `html<br><template iterator:it={list}><p key={it.value.id}>{it.value.name}</p></template>`      | ❌                               | First/last detect karna        |
| `<slot>`                 | `name`                        | `html<br><slot name="header"></slot>`                                                           | ❌                               | Parent se content lana         |

# 🔥 FULL BEGINNER PROJECT EXAMPLE

### HTML

```html id="example1"
<template>
    <lightning-card title="User Form">

        <lightning-input label="Name" onchange={handleChange}></lightning-input>

        <lightning-button label="Show" onclick={handleClick}></lightning-button>

        <template lwc:if={name}>
            <p>Hello {name}</p>
        </template>

    </lightning-card>
</template>
```

---

### JS

```javascript id="example2"
import { LightningElement } from 'lwc';

export default class Demo extends LightningElement {
    name = '';

    handleChange(event) {
        this.name = event.target.value;
    }

    handleClick() {
        console.log('Clicked');
    }
}
```

---

### 🧠 Hinglish Explanation

* Input → user se data le raha hai
* Button → click event handle kar raha hai
* `lwc:if` → condition check
* `{name}` → dynamic binding

# 🔷 18. FULL MINI PROJECT

### JS

```javascript
import { LightningElement } from 'lwc';

export default class Demo extends LightningElement {

    name = '';

    handleChange(event) {
        this.name = event.target.value;
    }

    handleClick() {
        alert(this.name);
    }

    get upperName() {
        return this.name.toUpperCase();
    }

}
```

---

### HTML

```html
<template>

    <lightning-input onchange={handleChange}></lightning-input>

    <lightning-button label="Show" onclick={handleClick}></lightning-button>

    <p>{upperName}</p>

</template>
```
