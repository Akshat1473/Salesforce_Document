# 🔷 1. UI Record API kya hai?

Ye Salesforce ka ek set hai jo LWC me use hota hai:

* Record **fetch (get)**
* Record **create**
* Record **update**
* Record **delete**

👉 Direct UI layer se kaam hota hai (Apex ki zarurat nahi hoti)

📦 Import:

```js id="cp6646"
import { 
    getRecord, 
    createRecord, 
    updateRecord, 
    deleteRecord 
} from 'lightning/uiRecordApi';
```

---

# 🔷 2. Record Fetch karna (getRecord)

## ✅ Use Case:

* Record ka data UI me dikhana
* Account, Contact details show karna

---

### 📌 Example:

#### JS:

```js id="k2mv31"
import { LightningElement, wire, api } from 'lwc';
import { getRecord } from 'lightning/uiRecordApi';

const FIELDS = [
    'Account.Name',
    'Account.Industry',
    'Account.Phone'
];

export default class AccountViewer extends LightningElement {
    @api recordId;

    @wire(getRecord, { recordId: '$recordId', fields: FIELDS })
    account;

    get name() {
        return this.account.data ? this.account.data.fields.Name.value : '';
    }
}
```

---

#### HTML:

```html id="tukctt"
<template>
    <lightning-card title="Account Info">
        <p>Name: {name}</p>
    </lightning-card>
</template>
```

---

## 🔥 Important:

* `@wire` automatically data fetch karta hai
* `$recordId` reactive hota hai
* `fields` me field API names dene hote hain

# 🔷 4. Record Create karna (createRecord)

## ✅ Use Case:

* New Account / Contact create karna
* Form submit

---

### 📌 Example:

```js id="mmmqoe"
import { LightningElement } from 'lwc';
import { createRecord } from 'lightning/uiRecordApi';

export default class CreateAccount extends LightningElement {

    handleCreate() {
        const fields = {
            Name: 'New Account',
            Industry: 'Technology'
        };

        const recordInput = { apiName: 'Account', fields };

        createRecord(recordInput)
            .then(result => {
                console.log('Record created: ', result.id);
            })
            .catch(error => {
                console.error(error);
            });
    }
}
```

---

## 🔥 Important:

* `apiName` = object ka API name
* `fields` = key-value pairs
* Return me `recordId` milta hai

# 🔷 5. Record Update karna (updateRecord)

## ✅ Use Case:

* Edit form
* Inline editing

---

### 📌 Example:

```js id="i1b8n7"
import { updateRecord } from 'lightning/uiRecordApi';

const fields = {
    Id: '001XXXXXXXXXXXX',
    Name: 'Updated Account Name'
};

const recordInput = { fields };

updateRecord(recordInput)
    .then(() => {
        console.log('Updated successfully');
    })
    .catch(error => {
        console.error(error);
    });
```

---

## 🔥 Important:

* `Id` mandatory hai
* Sirf updated fields bhejo

# 🔷 8. getFieldValue helper

## ✅ Use Case:

Safe way to access fields

---

### Example:

```js id="1mne6w"
import { getRecord, getFieldValue } from 'lightning/uiRecordApi';
import NAME_FIELD from '@salesforce/schema/Account.Name';

get name() {
    return getFieldValue(this.account.data, NAME_FIELD);
}
```

# 🔷 12. getRecord vs Apex
