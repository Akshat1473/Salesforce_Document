# 🧠 How to Use This Table (Very Important)


### ✅ 2. In Batch Apex

* Each batch chunk = **new transaction**
* Limits reset for each `execute()` method

👉 Example:

```apex
global void execute(Database.BatchableContext bc, List<Account> scope) {
    // SOQL, DML limits apply per chunk
}
```
