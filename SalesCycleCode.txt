Neeचे **ek single Apex example script** diya hai jo **end-to-end Salesforce sales cycle** ko simulate karta hai. Isme Campaign → Lead → Conversion → Account/Contact → Product/Pricebook → Opportunity → OpportunityLineItem → Quote → Order ke saath **Task + Files + Attachment** bhi create kiye gaye hain.
Ye flow typical **Salesforce Sales Cloud** implementation ko represent karta hai.

---

# Complete Apex Example (Full Sales Cycle + Files + Task + Attachment)

```apex
// ==========================
// 1. CREATE CAMPAIGN
// ==========================
Campaign camp = new Campaign(
    Name = 'Laptop Marketing Campaign',
    IsActive = true
);
insert camp;


// ==========================
// 2. CREATE LEAD
// ==========================
Lead lead = new Lead(
    LastName = 'Sharma',
    Company = 'ABC Pvt Ltd',
    Status = 'Open - Not Contacted'
);
insert lead;


// ==========================
// 3. CREATE TASK FOR LEAD
// ==========================
Task leadTask = new Task(
    Subject = 'Initial Lead Call',
    Status = 'Not Started',
    Priority = 'Normal',
    WhoId = lead.Id
);
insert leadTask;


// ==========================
// 4. CONVERT LEAD
// ==========================
Database.LeadConvert lc = new Database.LeadConvert();
lc.setLeadId(lead.Id);
lc.setConvertedStatus('Qualified');

Database.LeadConvertResult lcr = Database.convertLead(lc);

Id accId = lcr.getAccountId();
Id conId = lcr.getContactId();


// ==========================
// 5. CREATE PRODUCT
// ==========================
Product2 prod = new Product2(
    Name = 'Laptop',
    ProductCode = 'LP100',
    IsActive = true
);
insert prod;


// ==========================
// 6. GET STANDARD PRICEBOOK
// ==========================
Pricebook2 stdPB = [
    SELECT Id
    FROM Pricebook2
    WHERE IsStandard = true
    LIMIT 1
];


// ==========================
// 7. STANDARD PRICE ENTRY
// ==========================
PricebookEntry stdEntry = new PricebookEntry(
    Pricebook2Id = stdPB.Id,
    Product2Id = prod.Id,
    UnitPrice = 50000,
    IsActive = true
);
insert stdEntry;


// ==========================
// 8. CUSTOM PRICEBOOK
// ==========================
Pricebook2 customPB = new Pricebook2(
    Name = 'Dealer Price Book',
    IsActive = true
);
insert customPB;


// ==========================
// 9. CUSTOM PRICE ENTRY
// ==========================
PricebookEntry customEntry = new PricebookEntry(
    Pricebook2Id = customPB.Id,
    Product2Id = prod.Id,
    UnitPrice = 45000,
    IsActive = true
);
insert customEntry;


// ==========================
// 10. CREATE OPPORTUNITY
// ==========================
Opportunity opp = new Opportunity(
    Name = 'Laptop Deal',
    StageName = 'Prospecting',
    CloseDate = Date.today().addDays(30),
    AccountId = accId,
    Pricebook2Id = customPB.Id
);
insert opp;


// ==========================
// 11. OPPORTUNITY PRODUCT
// ==========================
OpportunityLineItem oli = new OpportunityLineItem(
    OpportunityId = opp.Id,
    PricebookEntryId = customEntry.Id,
    Quantity = 2,
    UnitPrice = 45000
);
insert oli;


// ==========================
// 12. CREATE QUOTE
// ==========================
Quote q = new Quote(
    Name = 'Laptop Quote',
    OpportunityId = opp.Id,
    Pricebook2Id = customPB.Id
);
insert q;


// ==========================
// 13. QUOTE LINE ITEM
// ==========================
QuoteLineItem qli = new QuoteLineItem(
    QuoteId = q.Id,
    PricebookEntryId = customEntry.Id,
    Quantity = 2,
    UnitPrice = 45000
);
insert qli;


// ==========================
// 14. CREATE ORDER
// ==========================
Order ord = new Order(
    AccountId = accId,
    EffectiveDate = Date.today(),
    Status = 'Draft',
    Pricebook2Id = customPB.Id
);
insert ord;


// ==========================
// 15. ORDER ITEM
// ==========================
OrderItem oi = new OrderItem(
    OrderId = ord.Id,
    PricebookEntryId = customEntry.Id,
    Quantity = 2,
    UnitPrice = 45000
);
insert oi;


// ==========================
// 16. ADD FILE TO OPPORTUNITY
// ==========================
ContentVersion file = new ContentVersion(
    Title = 'Laptop Proposal',
    PathOnClient = 'LaptopProposal.pdf',
    VersionData = Blob.valueOf('Sample Proposal File')
);
insert file;

ContentVersion cv = [
    SELECT Id, ContentDocumentId
    FROM ContentVersion
    WHERE Id = :file.Id
];

ContentDocumentLink cdl = new ContentDocumentLink(
    ContentDocumentId = cv.ContentDocumentId,
    LinkedEntityId = opp.Id,
    ShareType = 'V'
);
insert cdl;


// ==========================
// 17. ADD ATTACHMENT
// ==========================
Attachment att = new Attachment(
    Name = 'Contract.txt',
    ParentId = opp.Id,
    Body = Blob.valueOf('Sample Contract Data')
);
insert att;


// ==========================
// 18. CREATE TASK FOR OPPORTUNITY
// ==========================
Task oppTask = new Task(
    Subject = 'Follow up with customer',
    Status = 'Not Started',
    Priority = 'High',
    WhatId = opp.Id
);
insert oppTask;

System.debug('Complete Salesforce Sales Cycle Created');
```

# 1️⃣ Profile Query (Best Practice)

⚠️ **Profile Apex se create nahi kar sakte**, isliye existing profile query karte hain.

```apex
Profile p = [
    SELECT Id, Name
    FROM Profile
    WHERE Name = 'Standard User'
    LIMIT 1
];
```

Required field: `Name`

---

# 2️⃣ Create User (Correct Required Fields)

```apex
User u = new User(

    FirstName = 'Rahul',
    LastName = 'Sharma',

    Email = 'rahul@testorg.com',

    Username = 'rahul'+DateTime.now().getTime()+'@testorg.com',

    Alias = 'rshrm',

    TimeZoneSidKey = 'Asia/Kolkata',

    LocaleSidKey = 'en_US',

    EmailEncodingKey = 'UTF-8',

    LanguageLocaleKey = 'en_US',

    ProfileId = p.Id

);

insert u;
```

### Required Fields for User

| Field             | Description            |
| ----------------- | ---------------------- |
| Username          | Unique login           |
| Alias             | 8 character short name |
| Email             | User email             |
| ProfileId         | Security profile       |
| TimeZoneSidKey    | Timezone               |
| LocaleSidKey      | Locale                 |
| EmailEncodingKey  | Encoding               |
| LanguageLocaleKey | Language               |

# 5️⃣ Using UserInfo Class (Current User Info)

`UserInfo` class runtime user details deti hai.

Example:

```apex
System.debug('Current User Id: ' + UserInfo.getUserId());

System.debug('User Name: ' + UserInfo.getUserName());

System.debug('User Profile Id: ' + UserInfo.getProfileId());
```

Common methods:

| Method                       | Description      |
| ---------------------------- | ---------------- |
| UserInfo.getUserId()         | Current user id  |
| UserInfo.getUserName()       | Current username |
| UserInfo.getProfileId()      | Current profile  |
| UserInfo.getOrganizationId() | Org id           |

Neeche **proper Apex examples** diye gaye hain:

---

# 1️⃣ Create Role by Apex

```apex
UserRole salesManagerRole = new UserRole(

    Name = 'Sales Manager',
    DeveloperName = 'Sales_Manager',

    // Parent role (optional)
    ParentRoleId = null

);

insert salesManagerRole;
```

### Important Fields

| Field         | Required | Description    |
| ------------- | -------- | -------------- |
| Name          | ✅        | Role name      |
| DeveloperName | ✅        | API name       |
| ParentRoleId  | ❌        | Role hierarchy |

---

# 2️⃣ Create Child Role (Hierarchy)

```apex
UserRole salesRepRole = new UserRole(

    Name = 'Sales Representative',

    DeveloperName = 'Sales_Rep',

    ParentRoleId = salesManagerRole.Id

);

insert salesRepRole;
```

Hierarchy ban jayega:

```
Sales Manager
      ↓
Sales Representative
```

---

# 3️⃣ Assign Role to User
