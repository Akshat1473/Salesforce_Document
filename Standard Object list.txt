# 3. Polymorphic Fields in Salesforce

A **polymorphic field can reference multiple object types**.

| Field            | Used In Object      | Can Reference                                        |
| ---------------- | ------------------- | ---------------------------------------------------- |
| WhoId            | Task, Event         | Lead, Contact                                        |
| WhatId           | Task, Event         | Account, Opportunity, Case, Campaign, Custom Objects |
| OwnerId          | Most objects        | User, Queue                                          |
| CreatedById      | All objects         | User                                                 |
| LastModifiedById | All objects         | User                                                 |
| ParentId         | Various objects     | Multiple record types                                |
| RelatedRecordId  | FeedItem            | Any record                                           |
| LinkedEntityId   | ContentDocumentLink | Any record                                           |
| UserOrGroupId    | Sharing objects     | User, Public Group                                   |
| WhoCount         | Task/Event          | Contact/Lead counts                                  |

```
Contact / Lead
      │
      │ (WhoId)
      │
     Task / Event

      │ (WhatId)
```

**WhoId → Person involved**
